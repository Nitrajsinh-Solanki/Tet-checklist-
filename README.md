# TET-1 અભ્યાસ સાથી

ગુજરાત TET-1 પરીક્ષાની તૈયારી માટેનું સરળ, મોબાઇલ-ફ્રેન્ડલી ગુજરાતી checklist website.

## સુવિધાઓ
- પાંચ વિષયો માટે topic checklist
- કુલ અને વિષયવાર પ્રગતિ
- પૂર્ણ / બાકી ફિલ્ટર અને શોધ
- JSON backup અને restore
- કોઈ backend અથવા database નહીં
- પ્રગતિ browser ના localStorage માં જ સાચવાય છે

## ચલાવવાની રીત
આ repository માંથી GitHub Pages સક્રિય કરો:
1. Repository ના **Settings → Pages** ખોલો.
2. **Deploy from a branch** પસંદ કરો.
3. Branch તરીકે **main** અને folder તરીકે **/(root)** પસંદ કરો.
4. Save કરો. થોડી વારમાં Pages URL ઉપલબ્ધ થશે.

અથવા `index.html` ને સીધું browser માં ખોલો.

## નોંધ
આ સ્વતંત્ર અભ્યાસ સાધન છે, SEBનું સત્તાવાર ઉત્પાદન નથી. વિષયોની યાદી અભ્યાસ આયોજન માટે છે; પરીક્ષા પહેલાં State Examination Board ની તાજેતરની સત્તાવાર સૂચના અને સુધારેલા syllabus સાથે સરખાવી લેવી.

## ડેટા અને ગોપનીયતા
કોઈ account કે server-side database નથી. Checkbox ની સ્થિતિ આ browser/device ના localStorage માં રહે છે. Browser data સાફ કરતાં પહેલાં JSON backup લઈ લો. બીજા device પર JSON restore કરી શકાય છે.
